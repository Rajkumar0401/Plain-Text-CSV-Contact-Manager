# Contact Manager

A simple **command-line Contact Manager** built with Python that stores contact information in a CSV file.

## 📋 Features

* Add new contacts
* View and search contacts
* Update existing contacts
* Delete contacts
* Automatically creates `contacts.csv`
* Uses safe `with open(...)` file handling

## 📁 Structure

```text
contact-manager/
├── contacts.csv
├── manager.py
├── README.md
└── .gitignore
```

## 🗂️ Contact Fields

* Name
* Phone Number
* Email Address

## 🚀 Run

```bash
python manager.py
```
